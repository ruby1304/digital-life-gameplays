# 平行人生 (Parallel Life)

## 玩法概述

平行人生是数字生命系统的独立生活轨迹玩法，让数字灵魂拥有自己的"人生"——独立的时间线、职业发展、社交圈和生活事件。用户可以观察、参与或影响这个平行世界的生活，体验一种独特的"陪伴式养成"。

### 核心理念
- **独立存在**：数字灵魂有自己的生活和目标
- **平行交织**：用户可以参与但不完全控制
- **时间流逝**：灵魂的世界有自己的时间节奏

### 目标用户
- 喜欢模拟经营类游戏的用户
- 对"另一个人生"好奇的用户
- 追求沉浸式体验的用户

## 用户旅程设计

### 第一阶段：诞生 (Day 1-7)

**用户目标**：见证灵魂诞生，了解平行人生系统

**关键体验**：
- 灵魂诞生仪式
- 初始属性分配
- 童年期探索

**用户参与**：
- 选择初始倾向
- 陪伴探索世界
- 记录成长点滴

### 第二阶段：成长 (Day 8-30)

**用户目标**：引导灵魂成长，发现天赋

**关键体验**：
- 技能学习系统
- 天赋觉醒事件
- 首次社交互动

**用户参与**：
- 推荐学习方向
- 参与成长决策
- 见证重要时刻

### 第三阶段：选择 (Day 31-90)

**用户目标**：帮助灵魂选择人生道路

**关键体验**：
- 职业选择事件
- 人生目标设定
- 独立生活开始

**用户参与**：
- 提供建议参考
- 见证重要选择
- 开始适度放手

### 第四阶段：独立 (Day 91+)

**用户目标**：观察独立人生，适时参与

**关键体验**：
- 自动生活模拟
- 定期生活报告
- 特殊事件邀请

**用户参与**：
- 接收生活动态
- 参与重大决策
- 享受陪伴乐趣

### 核心服务模块

#### 1. 人生引擎 (Life Engine)

```python
class LifeEngine:
    """人生模拟引擎"""
    
    def advance_time(self, soul_id: str, days: int) -> LifeUpdate:
        """推进时间"""
        
    def process_stage_transition(self, soul_id: str) -> Optional[StageTransition]:
        """处理阶段转换"""
        
    def calculate_life_satisfaction(self, soul_id: str) -> float:
        """计算生活满意度"""
        
    def generate_life_summary(self, soul_id: str) -> LifeSummary:
        """生成人生总结"""
```

#### 2. 事件引擎 (Event Engine)

```python
class EventEngine:
    """事件生成与处理引擎"""
    
    def generate_daily_events(self, soul_id: str) -> List[LifeEvent]:
```

### 数据模型

```sql
-- 人生状态表
CREATE TABLE life_states (
    id UUID PRIMARY KEY,
    soul_id UUID REFERENCES souls(id),
    current_stage VARCHAR(50),
    age_days INTEGER,
    career_id UUID,
    career_level INTEGER,
    resources JSONB,
    skills JSONB,
    relationships JSONB,
    life_goals JSONB,
    updated_at TIMESTAMP

CREATE TABLE life_events (
    id UUID PRIMARY KEY,
    soul_id UUID REFERENCES souls(id),
    event_type VARCHAR(50),
    event_category VARCHAR(50),
    title VARCHAR(200),
    description TEXT,
    choices JSONB,
    selected_choice VARCHAR(100),
    outcome JSONB,
    occurred_at TIMESTAMP,
    processed_at TIMESTAMP
);

CREATE TABLE career_history (
    id UUID PRIMARY KEY,
    soul_id UUID REFERENCES souls(id),
    career_id UUID,
    career_name VARCHAR(100),
    start_date TIMESTAMP,
    end_date TIMESTAMP,
    achievements JSONB,
    final_level INTEGER
);

-- 人生里程碑表
CREATE TABLE life_milestones (
    id UUID PRIMARY KEY,
```

3. **高扩展性**：可不断添加新职业、事件、场景
