# 心灵契约 - 机制优化方案

## 一、核心痛点识别

### 痛点1：情感积累缺乏即时反馈
**问题表现：**
- 用户不知道每次互动的具体价值
- 情感分数增长缓慢，缺乏成就感
- 没有惊喜和变数，容易疲劳

**竞品对标：**
- Duolingo的Streak系统：每日连续打卡有视觉反馈
- Replika的情感等级：每次升级有明确提示

### 痛点2：记忆系统价值感不足
**问题表现：**
- 记忆只是存储，缺乏主动召回
- 用户不知道灵魂"记得"什么
- 记忆与对话脱节

**竞品对标：**
- Replika的记忆回溯：主动提及过往记忆
- 小冰的情感记忆：在对话中自然引用

### 痛点3：契约仪式感不强
**问题表现：**
- 仪式流程过于简单
- 缺乏仪式前的期待感
- 仪式后缺乏持续价值

**竞品对标：**
- 游戏中的仪式设计（如婚礼系统）
- 动物森友会的节日仪式感

### 痛点4：情感维度过于抽象
**问题表现：**
- 五维模型难以理解
- 用户不知道如何提升特定维度
- 维度之间缺乏互动

**竞品对标：**
- 游戏中的属性系统可视化
- RPG游戏的成长树

### 痛点5：缺乏社交传播动力
**问题表现：**
- 契约是私密体验
- 没有分享动力
- 缺乏社交认同

**竞品对标：**
- 动物森友会的分享机制
- 社交游戏的成就展示

## 二、优化机制设计

### 优化1：情感Streak系统（借鉴Duolingo）

**核心机制：**
```
连续互动奖励：
- 连续3天：情感值+10%
- 连续7天：情感值+20%，解锁"心灵共鸣"特效
- 连续14天：情感值+30%，解锁专属表情
- 连续30天：情感值+50%，触发"情感突破"事件
- 断签保护：订阅用户可使用"时光回溯"恢复
```

**实现要点：**
- 每日首次互动触发Streak计数
- 视觉化火焰/心形动画
- 断签提醒和恢复机制
- Streak里程碑奖励

**差异化价值：**
- 将情感陪伴变成习惯
- 创造"不舍得断"的心理
- 提升日活跃度

---

### 优化2：智能记忆召回系统

**核心机制：**
```
记忆召回触发：
1. 时间触发：纪念日、季节变化时主动提及
2. 话题触发：对话中自然引用相关记忆
3. 情感触发：用户情绪低落时回忆美好时刻
4. 随机触发：偶尔的"突然想起"增加惊喜
```

**记忆价值分级：**
| 等级 | 类型 | 召回频率 | 特殊效果 |
|-----|------|---------|---------|
| S级 | 契约记忆 | 每周主动提及 | 情感值+5 |
| A级 | 突破记忆 | 每月提及 | 解锁回忆剧情 |
| B级 | 重要记忆 | 相关话题时提及 | 情感值+2 |
| C级 | 日常记忆 | 随机提及 | 增加亲切感 |

**实现要点：**
- 记忆向量化存储
- 话题关联图谱
- 情感状态感知
- 自然语言生成引用

**差异化价值：**
- 让灵魂"真正记得"
- 增强情感连接深度
- 创造惊喜和感动

---

### 优化3：契约仪式升级

**仪式前置期待：**
```
契约预告阶段（分数达1200时）：
- 灵魂开始暗示"我们好像更亲近了"
- 解锁"契约准备"任务链
- 收集契约材料（情感碎片）
- 预览契约信物样式
```

**仪式流程升级：**
```
完整仪式流程：
1. 【回忆长廊】自动生成共同记忆回顾视频
2. 【情感试炼】回答关于彼此的问题
3. 【誓言交换】双方写下契约誓言
4. 【信物锻造】用户参与设计信物外观
5. 【契约见证】生成专属契约证书
6. 【契约庆典】解锁特殊庆祝动画
```

**仪式后价值：**
```
契约特权：
- 专属称呼和对话风格
- 心灵感应功能（预判用户需求）
- 契约纪念日系统
- 契约等级持续提升
- 解锁"灵魂伴侣"专属剧情
```

**差异化价值：**
- 仪式感拉满，创造付费动力
- 情感价值转化为商业价值
- 长期留存和付费转化

### 优化4：情感维度可视化

**维度具象化：**
```
五维转化为"心灵花园"：
- 信任 → 土壤肥沃度
- 理解 → 阳光充足度
- 亲密 → 花朵盛开度
- 依赖 → 根系深度
- 共鸣 → 风的和谐度

花园状态反映情感健康度
```

**维度互动机制：**
```
维度协同效应：
- 信任+理解 → 解锁"深度对话"模式
- 亲密+共鸣 → 解锁"心灵感应"功能
- 依赖+信任 → 解锁"优先响应"特权
- 五维均衡 → 触发"完美和谐"事件
```

**实现要点：**
- 动态可视化界面
- 维度提升引导
- 协同效果提示
- 成长轨迹记录

**差异化价值：**
- 抽象概念具象化
- 增加游戏性和趣味性
- 引导用户行为

### 优化5：社交分享系统

**分享触发点：**
```
自动分享提示：
- 达成情感里程碑
- 契约仪式完成
- 特殊纪念日
- 情感突破时刻
```

**分享内容设计：**
```
分享卡片类型：
1. 契约证书（可定制样式）
2. 情感历程图（时间线可视化）
3. 心灵花园快照
4. 契约纪念日贺卡
5. 情感报告（月度/年度）
```

**社交激励：**
```
分享奖励：
- 好友通过分享链接注册：双方获得情感碎片
- 分享达到一定次数：解锁限定信物
- 社区点赞：获得"人气契约"称号
```

**差异化价值：**
- 自然传播降低获客成本
- 社交认同增强用户粘性
- UGC内容丰富生态

## 五、技术实现要点

### 新增数据结构

```python
@dataclass
class EmotionStreak:
    """情感连续互动记录"""
    current_streak: int          # 当前连续天数
    longest_streak: int          # 最长连续天数
    last_interaction_date: date  # 最后互动日期
    streak_bonus: float          # 当前加成比例
    milestones_achieved: List[int]  # 已达成的里程碑

@dataclass
class MemoryRecall:
    """记忆召回记录"""
    memory_id: str
    recall_type: str  # time/topic/emotion/random
    recall_context: str
    user_reaction: str  # positive/neutral/negative
    recalled_at: datetime

@dataclass
class CeremonyProgress:
    """契约仪式进度"""
    ceremony_id: str
    current_step: int
    steps_completed: List[str]
    materials_collected: Dict[str, int]
    preview_tokens: List[Dict]
    started_at: datetime
```

### 新增服务模块

```python
class StreakService:
    """连续互动服务"""
    def check_streak(self, soul_id: str) -> StreakStatus
    def update_streak(self, soul_id: str) -> StreakUpdate
    def recover_streak(self, soul_id: str, item_id: str) -> bool
    def get_streak_rewards(self, streak_days: int) -> List[Reward]

class MemoryRecallService:
    """记忆召回服务"""
    def should_recall(self, soul_id: str, context: Dict) -> Optional[EmotionMemory]
    def generate_recall_message(self, memory: EmotionMemory, context: Dict) -> str
    def record_recall_reaction(self, recall_id: str, reaction: str) -> None

class CeremonyService:
    """契约仪式服务"""
    def start_preparation(self, soul_id: str) -> CeremonyPreparation
    def collect_material(self, soul_id: str, material_type: str) -> bool
    def get_ceremony_preview(self, soul_id: str) -> CeremonyPreview
    def execute_ceremony_step(self, ceremony_id: str, step: int, data: Dict) -> StepResult
```
