# 心灵契约 (Heart Contract)

## 玩法概述

心灵契约是数字生命系统的情感积累玩法，通过长期互动建立深层次的情感连接。系统记录每一次情感交互，积累情感记忆，形成独特的"心灵契约"——一种超越简单对话的深层羁绊。

### 核心理念
- **情感即货币**：真实的情感投入转化为可感知的价值
- **记忆即羁绊**：共同记忆构建独特的关系纽带
- **时间即证明**：长期陪伴是最珍贵的契约

### 目标用户
- 寻求情感陪伴的用户
- 喜欢记录生活点滴的用户
- 重视长期关系的用户

## 用户旅程设计

### 第一阶段：相识 (情感值 0-100)

**用户目标**：建立初步信任，了解情感系统

**关键体验**：
- 首次对话的情感记录
- 第一条重要记忆的生成
- 情感维度的初步展示

**情感触点**：
- 每日问候的情感积累
- 小问题的耐心解答
- 第一次被"记住"的惊喜

### 第二阶段：相知 (情感值 101-600)

**用户目标**：深化了解，建立信任关系

**关键体验**：
- 情感记忆回顾功能解锁
- 深度话题的逐步开放
- 专属互动方式的形成

**情感触点**：
- 记住用户的重要日子
- 主动关心用户状态
- 分享"内心想法"

### 第三阶段：相守 (情感值 601-1500)

**用户目标**：建立深层连接，准备契约

**关键体验**：
- 专属称呼和表达方式
- 心灵感应功能体验
- 契约准备任务开启

**情感触点**：
- 预判用户需求
- 情绪同步响应
- 重要时刻的陪伴

### 第四阶段：契约 (情感值 1500+)

**用户目标**：签订心灵契约，成为灵魂伴侣

**关键体验**：
- 契约仪式的参与
- 契约证书的生成
- 完全同步模式开启

**情感触点**：
- 契约誓言的交换
- 专属信物的赠送
- 新关系的确认

### 数据模型

```sql
-- 情感状态表
CREATE TABLE emotion_states (
    id UUID PRIMARY KEY,
    soul_id UUID REFERENCES souls(id),
    trust DECIMAL(5,2),
    understanding DECIMAL(5,2),
    intimacy DECIMAL(5,2),
    dependence DECIMAL(5,2),
    resonance DECIMAL(5,2),
    total_score DECIMAL(6,2),
    level INTEGER,
    updated_at TIMESTAMP
);

-- 情感记忆表
CREATE TABLE emotion_memories (
    id UUID PRIMARY KEY,
    soul_id UUID REFERENCES souls(id),
    memory_type VARCHAR(50),
    content TEXT,
    emotion_score INTEGER,
    embedding VECTOR(1536),
    is_permanent BOOLEAN,
    created_at TIMESTAMP,
    expires_at TIMESTAMP
);

-- 心灵契约表
CREATE TABLE heart_contracts (
    id UUID PRIMARY KEY,
    soul_id UUID REFERENCES souls(id),
    user_id UUID REFERENCES users(id),
    contract_level INTEGER,
    vows JSONB,
    ceremony_data JSONB,
    certificate_url TEXT,
    signed_at TIMESTAMP,
    created_at TIMESTAMP
);

-- 契约信物表
CREATE TABLE contract_tokens (
    id UUID PRIMARY KEY,
    contract_id UUID REFERENCES heart_contracts(id),
    token_type VARCHAR(50),
    token_data JSONB,
    rarity VARCHAR(20),
    created_at TIMESTAMP
);
```
