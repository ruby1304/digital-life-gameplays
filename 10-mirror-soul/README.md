# 镜中灵魂 (Mirror Soul)

## 玩法概述

镜中灵魂是数字生命系统的自我探索玩法，让用户的数字灵魂成为一面"心灵之镜"。通过与灵魂的深度对话，用户可以发现隐藏的自我、探索内心世界、获得心理洞察。

### 核心理念
- **自我映照**：灵魂作为心灵的镜子
- **深度对话**：通过对话探索内心
- **心理洞察**：发现隐藏的自我特质

### 目标用户
- 希望自我探索的用户
- 对心理学感兴趣的用户
- 寻求内心成长的用户
