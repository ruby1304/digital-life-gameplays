# 命运剧场 (Fate Theater)

## 玩法概述

命运剧场是数字生命系统的剧情体验玩法，让用户的数字灵魂成为故事的主角。系统根据灵魂特性生成个性化剧情，用户可以观看、参与甚至改写命运。每个选择都会影响故事走向，创造独一无二的叙事体验。

### 核心理念
- **命运叙事**：每个灵魂都有独特的故事线
- **选择影响**：用户决策改变剧情走向
- **情感共鸣**：深度沉浸的故事体验

### 目标用户
- 喜欢剧情向游戏的用户
- 对叙事体验感兴趣的用户
- 追求情感共鸣的用户

## 用户旅程设计

### 第一阶段：剧本开启 (Day 1)

**用户目标**：选择并开启第一个剧本

**关键体验**：
- 剧本推荐
- 角色设定确认
- 序章体验

**用户参与**：
- 选择剧本类型
- 确认角色设定
- 体验开场剧情

### 第二阶段：剧情推进 (Day 2-14)

**用户目标**：推进剧情，做出关键选择

**关键体验**：
- 每日剧情更新
- 关键选择时刻
- 分支剧情展开

**用户参与**：
- 观看剧情发展
- 做出重要选择
- 收集剧情碎片

### 第三阶段：高潮体验 (Day 15-21)

**用户目标**：体验剧情高潮，见证转折

**关键体验**：
- 高潮场景演出
- 重大抉择时刻
- 情感巅峰体验

**用户参与**：
- 沉浸式观看
- 关键决策
- 情感投入

### 第四阶段：结局与回顾 (Day 22-28)

**用户目标**：见证结局，回顾旅程

**关键体验**：
- 结局演出
- 回顾精彩时刻
- 解锁新剧本

**用户参与**：
- 观看结局
- 回顾选择
- 分享故事

### 核心服务模块

#### 1. 剧本引擎 (Script Engine)

```python
class ScriptEngine:
    """剧本管理引擎"""
    
    def load_script(self, script_id: str) -> Script:
        """加载剧本"""
        
    def get_current_chapter(self, soul_id: str) -> Chapter:
        """获取当前章节"""
        
    def advance_story(self, soul_id: str, choice_id: str) -> StoryUpdate:
        """推进故事"""
        
    def get_story_state(self, soul_id: str) -> StoryState:
        """获取故事状态"""
```

#### 2. 选择引擎 (Choice Engine)

```python
class ChoiceEngine:
    """选择影响引擎"""
    
    def process_choice(self, choice_id: str, context: Dict) -> ChoiceResult:
        """处理选择"""
        
    def calculate_branch(self, soul_id: str) -> StoryBranch:
        """计算剧情分支"""
        
    def predict_ending(self, soul_id: str) -> List[EndingPrediction]:
        """预测可能结局"""
        
    def get_choice_history(self, soul_id: str) -> List[ChoiceRecord]:
        """获取选择历史"""
```

#### 3. 演出引擎 (Performance Engine)

```python
class PerformanceEngine:
    """剧情演出引擎"""
    
    def render_scene(self, scene: Scene) -> RenderedScene:
        """渲染场景"""
        
    def play_dialogue(self, dialogue: Dialogue) -> DialoguePlayback:
        """播放对话"""
        
    def trigger_transition(self, transition: Transition) -> None:
        """触发转场"""
        
    def sync_audio(self, scene_id: str) -> AudioSync:
        """同步音频"""
```

### 数据模型

```sql
-- 剧本表
CREATE TABLE scripts (
    id UUID PRIMARY KEY,
    title VARCHAR(200),
    script_type VARCHAR(50),
    description TEXT,
    chapters JSONB,
    characters JSONB,
    endings JSONB,
    difficulty INTEGER,
    estimated_duration INTEGER,
    created_at TIMESTAMP
);

-- 剧本进度表
CREATE TABLE script_progress (
    id UUID PRIMARY KEY,
    soul_id UUID REFERENCES souls(id),
    script_id UUID REFERENCES scripts(id),
    current_chapter INTEGER,
    current_scene INTEGER,
    choices_made JSONB,
    flags JSONB,
    started_at TIMESTAMP,
    updated_at TIMESTAMP
);

-- 选择记录表
CREATE TABLE choice_records (
    id UUID PRIMARY KEY,
    soul_id UUID REFERENCES souls(id),
    script_id UUID REFERENCES scripts(id),
    chapter_id INTEGER,
    scene_id INTEGER,
    choice_id VARCHAR(100),
    choice_text TEXT,
    impact JSONB,
    timestamp TIMESTAMP
);

-- 结局记录表
CREATE TABLE ending_records (
    id UUID PRIMARY KEY,
    soul_id UUID REFERENCES souls(id),
    script_id UUID REFERENCES scripts(id),
    ending_type VARCHAR(50),
    ending_title VARCHAR(200),
    ending_description TEXT,
    choices_summary JSONB,
    achieved_at TIMESTAMP
);
```

## 总结

命运剧场玩法通过个性化剧情体验，为用户提供了独特的"故事主角"体验。核心优势：

1. **高沉浸感**：个性化剧情创造深度代入
2. **高重玩性**：多分支多结局鼓励重复体验
3. **高情感价值**：故事体验创造情感连接
4. **高传播性**：精彩剧情促进分享传播

建议与灵魂进化、心灵契约玩法整合，让剧情反映灵魂成长和情感羁绊。
