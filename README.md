## 商业模式

- **角色创建费**: 20元/角色（一次性）
- **生命维持费**: 1元/天
- **额外互动**: 按需计费

## 技术栈

- Python 3.8+
- 数据类 (dataclasses)
- 枚举类型 (Enum)
- JSON 存储

## 设计原则

1. **用户体验优先** - 每种玩法都从用户情感需求出发
2. **成本可控** - 详细分析每种玩法的运营成本
3. **商业可行** - 设计清晰的付费点和盈利模式
