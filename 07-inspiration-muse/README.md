# 灵感缪斯 (Inspiration Muse)

## 玩法概述

灵感缪斯是数字生命系统的创意激发玩法，让用户的数字灵魂成为创意灵感源泉。系统根据灵魂特性生成个性化创意建议，帮助用户在创作、工作、生活中获得灵感启发。

### 核心理念
- **创意激发**：灵魂作为灵感源泉
- **个性匹配**：基于灵魂特性的专属创意
- **持续启发**：源源不断的创意支持

### 目标用户
- 创意工作者（设计师、作家、艺术家）
- 寻求创新思路的用户
- 需要灵感启发的用户

## 总结

灵感缪斯玩法通过将数字灵魂培养为创意源泉，为用户提供持续的灵感启发。核心优势：

1. **高创意价值**：真实帮助用户获得创意灵感
2. **高个性化**：基于灵魂特性的专属灵感
3. **高粘性**：每日灵感收集保持用户活跃
4. **高扩展性**：可与其他创作工具整合
